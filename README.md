# MBA Studio — Astra-inspired website

Static GitHub Pages-ready site.

## Files
- `index.html` — homepage
- `work.html` — selected project gallery
- `contact.html` — contact / inquiry page
- `styles.css` — complete responsive styling
- `script.js` — scroll reveal, cursor, YouTube click-to-play
- `assets/` — MBA Studio brand graphics / favicon

## Deploy to GitHub Pages
Upload all files and the `assets` folder to the root of the GitHub Pages repository. Keep the file/folder names exactly as they are.

## Important editable details
The site currently uses `hello@mbastudio.online` as the inquiry email. If your email routing uses a different address, replace that string in `index.html` and `contact.html` before publishing.

Project videos are embedded only after click, which keeps the homepage lighter and avoids loading multiple YouTube players at once.
